# TSACI Website Requirements Document
## Tupi Supreme Activated Carbon, Inc. - Professional Website Specifications

**Document Version:** 1.0  
**Date:** 2024  
**Project:** TSACI Corporate Website

## 1. Executive Summary

### 1.1 Project Overview
Develop a professional, B2B-focused website for Tupi Supreme Activated Carbon, Inc. (TSACI) that positions the company as a leading provider of activated carbon solutions for municipal water treatment facilities and industrial applications.

### 1.2 Website Objectives
1. **Establish Market Leadership:** Position TSACI as the premier choice for municipal water treatment facilities
2. **Generate Qualified Leads:** Attract and convert B2B clients through inquiry forms and quote requests
3. **Build Credibility:** Showcase expertise, certifications, and successful client relationships
4. **Product Information:** Clearly present activated carbon products and specifications
5. **Support Sales:** Provide resources for sales team (spec sheets, technical documentation)
6. **Sustainability Messaging:** Highlight zero-waste operations and environmental responsibility

### 1.3 Success Metrics
- Lead generation (contact form submissions, quote requests)
- Technical documentation downloads
- Time on site, page views
- Bounce rate improvement
- Mobile traffic engagement
- Search engine rankings for key terms

## 2. Target Audience Analysis

### 2.1 Primary Audience

#### Municipal Water Treatment Facilities (KEY TARGET)
- **Role:** Water treatment plant managers, engineers, procurement officers
- **Needs:** Reliable activated carbon supply, technical specifications, certifications
- **Pain Points:** Quality consistency, supply reliability, technical support
- **Decision Process:** Research → Specification review → Request quotes → Vendor evaluation

#### Industrial Clients
- **Role:** Environmental engineers, facility managers, procurement
- **Needs:** Custom formulations, technical consultation, batch consistency
- **Applications:** Wastewater treatment, air purification, pharmaceutical processing

#### Horticultural Sector
- **Role:** Commercial growers, greenhouse operators, agricultural suppliers
- **Needs:** Growing mediums (coconut husk chips, coconut pit), bulk orders
- **Applications:** Horticulture, agriculture, professional growing

### 2.2 User Personas

**Persona 1: Municipal Water Treatment Manager**
- Technical background, safety-conscious
- Needs: Certifications, quality specs, case studies
- Values: Reliability, consistency, compliance

**Persona 2: Industrial Environmental Engineer**
- Highly technical, specification-focused
- Needs: Technical data sheets, application guides, custom solutions
- Values: Performance, customization, technical support

**Persona 3: Horticultural Buyer**
- Price-conscious, volume-focused
- Needs: Product specs, bulk pricing, availability
- Values: Quality, price, delivery reliability

## 7. Technical Specifications

### 7.1 Technology Stack

#### **Frontend:**
- HTML5, CSS3
- JavaScript (vanilla or lightweight framework)
- Responsive CSS framework (Tailwind CSS or Bootstrap)
- Font Awesome for icons

#### **Backend:**
- PHP 7.4+ (server-side processing)
- Form processing
- Email functionality

#### **Server Requirements:**
- Apache/Nginx web server
- PHP 7.4 or higher
- SSL certificate (HTTPS required)
- Email functionality

### 7.2 Performance Requirements

- **Page Load Time:** < 3 seconds
- **Mobile Performance:** Optimized for mobile networks
- **Image Optimization:** Compressed, WebP format
- **CDN:** For static assets (CSS, JS, images)
- **Caching:** Browser caching, server-side caching

### 7.3 SEO Requirements

#### **On-Page SEO:**
- Title tags (unique per page)
- Meta descriptions
- Header tags (H1-H6 structure)
- Alt text for images
- Internal linking structure
- URL structure (clean, descriptive)

#### **Keywords Focus:**
- Primary: "municipal water treatment activated carbon"
- Secondary: "granulated activated carbon", "water treatment carbon"
- Long-tail: "activated carbon for municipal water treatment facilities"
- Location-based: If applicable

#### **Technical SEO:**
- XML sitemap
- Robots.txt
- Structured data (Schema.org)
- Mobile-friendly (Google requirement)
- Fast loading times
- SSL certificate

### 7.4 Security Requirements

- **HTTPS:** SSL certificate required
- **Form Security:**
  - CSRF protection
  - Input sanitization
  - XSS prevention
  - SQL injection prevention (if database used)
- **Email Security:**
  - Header injection prevention
  - Email validation
- **Spam Protection:**
  - CAPTCHA or reCAPTCHA
  - Honeypot fields
  - Rate limiting
